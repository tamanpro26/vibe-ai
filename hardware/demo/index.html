The physical DHT11 sensor is offline -- these two buttons queue a manual trigger that the ESP32 itself picks up on its next poll (once per second) and fires exactly like a real sensor edge would, running the full AI pipeline (device-plan generation, buzzer, chasing LEDs) unchanged. This replaces the serial 'h'/'n' keystroke, not any of the AI/hardware logic downstream of it.
