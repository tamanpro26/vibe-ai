# Changelog

## 0.1.0 — 2026-07-09

Initial release.

- `@vibeai` chat participant: talk to your locally-running VibeAI
  multi-agent council from the VS Code Chat panel.
- **VibeAI: Fix/Explain Selected Code** — right-click any selection to send
  it (with file path and language context) through the full pipeline.
- Settings for server URL and optional bearer token.
- Clear, actionable error guidance when the local server isn't running.
